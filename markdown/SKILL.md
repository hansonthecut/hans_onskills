Find all the .md files and put them in one folder called all.markdowns. Make it non-destructive and merge instead. What this means is, you are just adding to the collection and updating where is needed. Do not delete or remove any files. Essentially, merge all the markdown files and if there is a duplicate for whatever reason, pick the one that is the newest since it will likely have the most information. At the end of that, open the folder for me in either finder or some native file managers depending on the operating system.
