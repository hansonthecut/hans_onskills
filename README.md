## 🛠 Global Installation & Sync

To synchronize these skills with your local Antigravity environment:
```bash
cp -R "/Volumes/990 2TB SSD/hans_onskills/"* "$HOME/.gemini/config/skills/"
```

All skills can be executed inside Antigravity by triggering `/<skill-name>` (e.g. `/audit`, `/visualtest`, `/verify`).
